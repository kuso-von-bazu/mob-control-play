# 乱世の潮流 — モブコントロール

**[ブラウザで遊ぶ](https://kuso-von-bazu.github.io/mob-control-play/)**

架空の中国地方で、小さな地方勢力の指導者として威信と国力を競うターン制のヘックスストラテジーです。

- 64×40ヘックス、5勢力、80ターン。
- 税と救済、農民蜂起、集団への物資提供・呼びかけ、軍事・交渉。
- ブラウザ内の保存・再開と、セーブファイルの書出し・読込。
- HEXAGAMEを拡張した地図エディタを同梱。

パソコンのChrome・Edgeとマウス操作を想定しています。ゲームバランスは初期調整段階です。

このリポジトリはGitHub Pagesへ配信するゲームファイルを管理しています。

[遊び方](https://kuso-von-bazu.github.io/mob-control-play/help.html) / [クレジット](https://kuso-von-bazu.github.io/mob-control-play/credits.html)

HEXAGAMEのマップエディタ・座標計算、Godot Engine、Noto Sans JPを利用しています。各コンポーネントの出典とライセンスはクレジットを参照してください。
